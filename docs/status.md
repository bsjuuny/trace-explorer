## 자동 검증
`pnpm verify`와 `pnpm e2e` 결과는 README의 명령으로 재현합니다. 2026-11-19 기준 `pnpm verify`(단위 테스트 42건)와 `pnpm e2e`(14건) 통과, `pnpm audit` 알려진 취약점 0건(Vite 7.3.8·Vitest 4.1.12·Zod 4.6.7). 이후 결과는 작업 보고에 기록합니다.

## 콘텐츠 검증 — **미완료**
- 검증된 실제 장소 0개(목표 30개), 검수된 미션 0개(목표 10개). 데모 8개는 수량에 포함하지 않습니다.
- `pnpm data:validate`는 공개 기준 위반을 "미완료"로 출력합니다(데모라서 정상).

## 현장 검증 — **미수행**
- 종로5가역 주변 15분 코스 실측 0회(목표 5회). 도보 ETA는 모두 `approximate`(데모 값).

## 외부 배포 — **미수행**
- 카페24 업로드, HTTPS 도메인 점검, OpenFreeMap 이용 조건·사용량 확인, iOS Safari/Android Chrome 실기기 검증 모두 미수행.

## 미완료·한계
- 지도는 OpenFreeMap(MapLibre)으로, 로컬에서 실제 타일 로딩·끌기·확대·마커를 E2E로 확인했습니다(headless Chrome, 소프트웨어 렌더링). OpenFreeMap의 이용 조건·사용량 한도·서울 지역 품질은 공식 확인 전이며, 실기기(iOS Safari·Android Chrome) 지도는 미검증입니다.
- 내 위치가 종로5가에서 3km 이상 떨어져 있으면(PC의 IP 추정·VPN 등) 그 위치를 쓰지 않고 종로5가역에서 시작합니다. 실제 GPS 기기에서의 동작은 미검증입니다.
- 법무: 약관·처리방침은 초안이며 위치정보법 적용·신고·지도 타일 요청(OpenFreeMap)에 포함되는 정보 판정이 필요합니다(`legal-launch-checklist.md`).
- 2026-11-19 코드 리뷰 후속 과제(`special-open` 규칙, 테마·미션 선택, 공개 검증 누락, 저장소 견고성, 지도 위치 버튼의 동의 우회 등)는 [code-review-2026-11-19.md](code-review-2026-11-19.md)에 있습니다.
- 매니페스트 아이콘은 SVG 하나뿐입니다(PNG 192/512·maskable·`apple-touch-icon` 없음).
- 접근성: 구조(라벨·44px·reduced-motion·텍스트 대체)는 반영했으나 스크린리더·200% 확대 실측은 하지 않았습니다.
- `import-places`(공공데이터 수집)는 빈 자리입니다. 외부 데이터 호출은 승인 후 별도 구현합니다.

## 명세 변경(사용자 결정, 2026-11-19)
- '길 안내 · 목적지' 카드(목적지 즉시 공개 버튼, 외부 지도 길 안내 링크)를 제거했습니다. 원 명세의 "탐험 종료 / 목적지 즉시 공개 / 외부 길 안내는 모든 단계에서 접근 가능" 중 **탐험 종료만 남았습니다.** 목적지는 탐험 종료·완료 시에만 공개됩니다.
- 이 변경으로 길을 못 찾는 사용자가 앱 안에서 목적지를 확인할 방법이 없습니다. 출시 전 현장 QA에서 사용성·안전 영향을 확인해야 합니다.
