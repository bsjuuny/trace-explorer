# 법적 출시 전 체크리스트 (개발용 초안 — 전문가 검토 필요)

앱 내 문서 초안: `apps/explorer/src/lib/legal.ts` (이용약관·개인정보 처리방침·위치기반서비스 약관·데이터 권리). 모두 **초안이며 사업자 정보 교체 지점이 `[대괄호]`로 남아 있습니다.** 법령·기관 안내는 변동되므로 출처 URL·확인일·재검증 책임자를 기록하고 공개 직전 재확인합니다(참고: 위치정보법, 개인정보 보호법, 위치정보지원센터, 개인정보 포털).

| 데이터 | 생성 | 전송 | 저장 | 삭제 |
|---|---|---|---|---|
| 현재 좌표 | 브라우저 Geolocation(클릭 시) | 운영자 서버로 전송 안 함(서버 없음). 좌표를 보내는 요청은 없음(타일은 보는 영역의 타일 좌표만 요청) — 네트워크 캡처로 **미검증** | 저장 안 함(메모리, 체크인 판정 후 폐기) | 즉시 |
| 동의 상태·문서 버전 | 앱 | 전송 안 함 | IndexedDB | 설정 > 내 기록 삭제 |

## 판정 필요(미완료)
- [ ] 위치정보법 적용 여부·신고·약관·동의 — 사업 주체와 위 흐름 기준으로 전문가 판정
- [ ] 개인정보 보호법상 처리 근거, 제3자 제공·위탁 여부(지도 타일 서버 OpenFreeMap 포함)
- [ ] 보유기간·법정 보존 대상 여부
- [ ] 만 14세 미만: **MVP는 이용 대상에서 제외**(UI·약관·QA에 반영됨). 정책 변경 시 법정대리인 동의 설계 필요
- [ ] 개정 시 재고지: 문서 버전(`CONSENT_VERSION`)이 바뀌면 저장된 동의가 무효화되어 동의 화면이 다시 나옴(동작 구현됨, 문서 내용은 미확정)
- [ ] 사업자 정보·문의처 교체, 약관 최종 문구 확정
- [ ] 2차 단계(제보·사진·계정) 도입 시 수집 항목·보관기간·권리 처리 별도 설계
