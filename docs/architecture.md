# 아키텍처

## 계층
`schemas`(타입·Zod) ← `core`(순수 로직, DOM 비의존) ← `explorer`/`admin`(UI). `data`는 데모 콘텐츠, `templates`는 빈 템플릿.

`PlaceRepository` 인터페이스 + `StaticPlaceRepository`(fetch + Zod). 이후 `ApiPlaceRepository`로 바꿔도 엔진·화면은 변하지 않습니다.

## 엔진 규칙 요약
- 판정은 `eligible / ineligible / unknown` 3값. 오래됐거나 검증 안 된 시간표·요금은 통과시키지 않고 `unknown`(데모 모드에서만 `allowUnverified`).
- 자정을 넘기는 운영시간은 전날(시작일)의 요일·월·휴관 여부로 판정한다(월요일 휴관인 곳도 일요일 밤 영업은 월요일 새벽까지 이어짐).
- 특별 휴관/개방(`exceptions`): `closed`는 항상 최우선. `special-open`은 자기 `open`·`close`·`mode`(선택 `lastEntryMinutesBeforeClose`·`feeKrw`)를 가지며, 해당 기간에는 정기 휴관일·일반 운영시간 대신 이 시간만 적용한다(기간 안이라도 시간 밖이면 운영시간 외, 자정을 넘기는 구간은 시작일 기준). 시간표 신선도가 `verified`가 아니면 통과시키지 않는 원칙은 동일. 공개 검증은 운영시간·일반 요금·요일 한정 요금·특별 개방 기간이 서로 겹치는 정책을 오류로 막는다(배열 순서 의존 제거).
- 미션 선택: 후보는 장소가 아니라 (장소, 미션) 단위로 평가한다. 테마는 `mission.themeId`로 판정하고(장소 분류는 보조·불일치 시 검증 경고), 공개 모드에서는 검수·안전검수가 끝난 미션만 쓴다. 한 장소에 쓸 수 있는 미션은 id 순으로 고정한 뒤 시드 난수로 고른다(비활성 테마의 미션은 테마를 지정하지 않아도 제외)(같은 시드면 같은 결과). 점수 상위 8곳(`topN`) 중 가중 무작위로 장소를 고른다(5에서 8로 넓힘: 점수 차가 작아 5로 자르면 데모 15곳 중 일부만 계속 나옴). 엔진 1.1.0, 가중치 w2.
- 15분 적합성: `이동 + 체류 + 단서(4) + 기록(2) + 여유(2) <= 요청 시간`. ETA는 `verified` 실측 우선, `approximate`는 직선거리 x 1.4 / 70m/분이며 직선 700m 초과·`unknown`은 제외.
- 점수 동점은 `placeId` 순. PRNG는 FNV-1a 해시 + mulberry32, 결과 메타에 엔진/가중치/PRNG 버전과 seed를 기록. 알고리즘을 바꾸면 `ENGINE_VERSION`·`SCORE_WEIGHTS_VERSION`을 올리고 회귀 테스트를 갱신합니다.
- 야외 미션은 06:00~19:00(도착 기준)만. 후보가 없으면 먼 곳을 고르지 않고 제안(시간 확대·무료 해제 등)을 돌려줍니다.
- 체크인: 반경 + 정확도 + 측정 시각(30초, 미래 시각·NaN·음수 정확도 거부)을 함께 판정. 완료 키 `missionId:placeId:startedAt`로 XP·도감 지급은 멱등. 현장 인증 없는 "기록만 저장"은 XP 0, 도감 미인증이며, 이후 현장 인증하면 인증으로 승격되고 XP를 지급(이미 인증된 장소만 once 정책으로 XP 차단). 진행 중 세션만 완료·체크인 가능.

## 서비스 지역
`SERVICE_AREAS`(core `geo.ts`)에 지역 id·이름·중심 좌표를 둔다(현재 종로5가역, 난곡우체국사거리). 사용자는 홈에서 출발 지역을 고르고, "내 위치로 탐험"은 3km 안의 가장 가까운 지역으로 매칭하며 어느 지역에서도 멀면 그 좌표를 쓰지 않고 선택한 지역 중심에서 시작한다. 장소에는 지역 필드가 없고, 출발점에서 직선 700m 이내(도보 ETA 계산 가능)인 장소만 후보가 되므로 지역은 자연스럽게 분리된다. 종로5가 장소만 사전 측정 ETA(`walkEstimate`)를 쓰고, 난곡 장소는 거리 기반 근사값을 쓴다. 난곡 중심 좌표는 임시값(`approximate: true`).

## 추가 힌트
`Place.extraHint`(선택, 1~120자, 공개 필드)가 있으면 탐험 중 "추가 힌트"에 그 문장과 도보 시간을 보여준다. 없으면 테마 이름(예: 식당)과 도보 시간으로 대체. 어드민 장소 편집에서 입력하며, 공개 검증은 힌트가 없으면 경고, 장소 이름이 들어 있으면 오류로 처리한다.

## 저장
IndexedDB `trace-explorer` v2(키-값). v1→v2 마이그레이션 포함. 저장: 동의 상태·도감/XP·진행 중 탐험. **이동 경로·좌표 이력은 저장하지 않음.** 복원 시 저장값을 신뢰하지 않는다: 진행 상태는 `restoreProgress`로 형식 검증·정규화하고, 세션의 장소·미션은 현재 번들의 같은 id 항목으로 교체(없으면 폐기). 삭제는 `deleteDatabase`로 실제 삭제하며, 다른 탭이 DB를 붙잡아 삭제가 막히면(`blocked`) "완료"로 안내하지 않고 다른 탭을 닫고 재시도하라고 알린다. DB 열기에 실패해도 다음 접근에서 재시도하고(영구 메모리 모드 고정 방지), 그동안의 쓰기는 보관했다가 DB가 열리면 한 트랜잭션으로 반영한다. 진행도와 세션도 한 트랜잭션으로 저장한다. 삭제가 막히면 화면 상태를 지우지 않는다. 세션의 GPS 출발점은 개인정보 원칙상 저장하지 않는다(복원 시 종로5가역 출발점으로 돌아감).

## 보안 경계
- 장소명·단서는 항상 plain text 렌더(`dangerouslySetInnerHTML` 금지 lint 규칙).
- CSP·Referrer-Policy를 `index.html` meta로 적용(외부 허용 도메인은 지도 타일 서버 `tiles.openfreemap.org`뿐). 호스팅이 응답 헤더를 지원하면 같은 정책을 헤더로도 적용.
- 공개 번들 allowlist: `adminNote`·`verifiedBy` 제거 후 그 산출물을 기준으로 공개 검증(데모·미검수·만료 차단). 소스맵 비공개. 날짜 필드는 스키마에서 실존 날짜·파싱 가능한 ISO로 검증.
- 데모 모드(`allowDemo`)는 번들이 전부 데모일 때만. `?seed=&now=`는 개발 서버 또는 `VITE_ENABLE_QA_PARAMS=true` 빌드에서만 동작.
- 서비스 워커: 캐시 이름에 빌드 해시, `trace-` 접두어 캐시만 정리, 내비게이션은 network-first(정상 HTML만 캐시), 런타임 캐시는 해시 에셋·셸 파일로 한정, `content.json`은 network-first + 24시간 TTL.
- 스키마에 문자열·배열 길이·체크인 반경(≤500m)·정확도(≤200m) 상한을 두어 변조된 대형 콘텐츠로 인한 정지를 막는다.
- 지도 위치 버튼은 위치 동의 시에만 노출. 체크인·XP는 서버 검증이 없는 클라이언트 신뢰 구조이므로 실제 가치가 있는 보상에 연결하지 않는다.
- 어드민은 `127.0.0.1` 바인딩(`allowedHosts` 명시), CSP·`no-referrer` 적용, 사용자 빌드에 미포함. 인증은 없음.
